# A股数据格式检查器 (ashare-data-inspector) v0.1

> **MODEL_NAME**: Grok  
> **实现分支**: grok/ashare-data-inspector-v0.1  
> **PR 标题**: Grok 实现 A股数据格式检查器 v0.1

一个**本地运行、离线优先、轻量化**的 A 股数据格式检查与标准化工具。  
服务于后续个股/组合回测项目的前置数据治理环节。

## 工具用途

本工具用于对本地 A 股交易数据文件进行：
- 数据上传与快速预览
- 字段自动识别 + 手动映射
- 多维度数据质量检查（日期有效性、缺失值、重复记录等）
- 标准化字段命名与格式转换
- 导出符合标准格式的 CSV，供后续回测或分析使用

## 非目标说明（v0.1 严禁功能）

- ❌ 不做任何回测、策略收益计算、绩效分析
- ❌ 不接 iFind / Wind / Choice / Tushare / AkShare 等金融数据库 API
- ❌ 不联网抓取数据
- ❌ 不做自动交易、账号登录、云同步
- ❌ 不上传用户数据到任何云端
- ❌ 不做复杂权限系统、Docker 容器化、前端框架、多用户支持
- ❌ 不删除重复记录、不自动填充缺失值、不删除异常值

**本工具完全本地运行，所有数据处理均在用户本地完成。**

## 安装依赖

```bash
cd ashare-data-inspector
pip install -r requirements.txt
```

requirements.txt 内容：
```
streamlit>=1.28.0
pandas>=2.0.0
openpyxl>=3.1.0
```

## 运行方式

```bash
cd ashare-data-inspector
streamlit run app.py
```

浏览器将自动打开本地页面（默认 http://localhost:8501）。

## 支持文件格式

- ✅ **.csv**（推荐，优先使用 UTF-8 with BOM 编码）
- ✅ **.xlsx**（Excel 2007+）
- ❌ **.xls**（暂不支持，需额外 xlrd 依赖；请另存为 .xlsx 或 .csv）

## 输入数据需要具备的字段

输入文件**至少应包含**以下可识别的列（支持中英文常见命名）：

- 日期列（trade_date / 日期 / 交易日期 等）
- 股票代码列（stock_code / 股票代码 / code 等）
- 收盘价列（close / 收盘价 等）

其他可选：复权收盘价、成交量、成交额、各类因子列、备注列。

## 字段映射说明

页面「字段映射」区域允许用户：
- **必选**：日期列、股票代码列、收盘价列
- **可选**：复权收盘价列、成交量列、成交额列、备注列
- **多选**：因子列（输出时自动加 `factor_` 前缀保留原字段名）

工具会根据常见命名进行**轻量默认猜测**，但**必须允许用户手动覆盖**选择。

**因子列处理规则**（已在 README 明确说明）：
- 选中的因子列将以 `factor_原列名` 的形式保留在标准化输出中
- 不进行数值强制转换，保留原始数据类型
- 若原列名与标准字段冲突，`factor_` 前缀可避免覆盖

## 数据质量检查说明

工具提供以下检查项（点击「执行数据质量检查」后展示）：

1. 日期列是否可解析为日期（统计无效数量）
2. 股票代码列空值数量
3. 收盘价列空值数量 + 非数值数量
4. 同一股票同一日期的重复记录数量（仅提示，不自动删除）
5. 每列缺失值数量与缺失率（%）
6. 数据日期范围（基于有效日期）
7. 售一股票数量
8. 总记录数

**重要**：检查结果仅供参考，**不会修改原始数据**。用户可根据报告决定后续处理策略。

## 标准化输出字段说明

标准化后 CSV 包含以下列（顺序可能因 pandas 版本略有差异）：

| 标准字段     | 说明                                      | 是否必含 | 来源          |
|--------------|-------------------------------------------|----------|---------------|
| trade_date   | 日期，格式 YYYY-MM-DD（字符串）            | 是       | 日期列映射    |
| stock_code   | 股票代码（字符串，已 strip）               | 是       | 股票代码列映射|
| close        | 收盘价（数值，错误值 → NaN）               | 是       | 收盘价列映射  |
| adj_close    | 复权收盘价（数值）                         | 否       | 可选映射      |
| volume       | 成交量（数值）                             | 否       | 可选映射      |
| amount       | 成交额（数值）                             | 否       | 可选映射      |
| factor_xxx   | 因子列（保留原值，加前缀）                 | 否       | 多选映射      |

**处理规则**（已在代码与界面明确）：
- 日期解析失败的行 → trade_date 为空字符串
- 数值转换失败 → 对应字段为 NaN
- **不删除任何行**
- **不填充任何缺失值**
- **不删除重复记录或异常值**
- 完全空行保留（用户可后续自行处理）

## 手动验证步骤

1. 准备一个包含日期、股票代码、收盘价的 CSV 或 xlsx 测试文件（可含中文列名）。
2. 运行 `streamlit run app.py`
3. 上传文件 → 确认预览正确显示。
4. 在「字段映射」区检查自动猜测是否合理，手动调整后点击「确认并应用字段映射」。
5. 点击「执行数据质量检查」，查看缺失值、重复记录、日期有效性等报告。
6. 点击「生成标准化数据」，预览前 10 行。
7. 点击「下载标准化 CSV」，保存文件。
8. 用 Excel 或 pandas 打开导出的 CSV，确认：
   - trade_date 为 YYYY-MM-DD 格式
   - stock_code 为字符串
   - close 等为数值列
   - factor_xxx 列存在且内容正确
9. 验证：原始文件中的空值、异常日期在标准化后正确体现为 NaN 或空字符串，且行数一致。
